# Roadmap

I want DeckPilot to stay focused on configuring DIY 12-key macropads. These are working priorities, not release promises or dates.

1. **Validate the hardware setup on more PCs.** The firmware guide records the board and bootloader I have actually tested; broader Windows and two-board checks come next.
2. **Make optional audio easier to opt into.** The soundboard is useful, but installing VB-CABLE by default adds friction for people who only want key actions.
3. **Reduce install friction.** Look at code signing when it is practical, and keep the installer and update path easy to understand.

The [open issue list](https://github.com/lolo34dr/deckpilot/issues) is the place to check current reports and suggest priorities. Released work belongs in the [changelog](CHANGELOG.md).
