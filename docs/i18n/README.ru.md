DeckPilot Настройка совместимых с Arduino Leonardo макропадов, которые уже отправляют **F13-F24** в качестве входов USB-клавиатуры, расположенных в **3 ряды 4 ключи**Физический порядок ключей может быть произвольным: управляемая калибровка отображает каждую кнопку в ее положении.

**Никаких дополнительных изменений драйвера или прошивки не требуется.** Интерфейс приложения в настоящее время на французском языке. Выберите язык выше для полного перевода README, включая техническую ссылку и историю версий. Переводы генерируются автоматически; этот английский оригинал является ссылкой.

<a id="features"></a>
## Особенности

- **Руководящая калибровка:** Определить все 12 Физические кнопки без перезагрузки макропада.
- **Установочный сборщик приложений:** Поиск меню «Пуск» и каталог приложений Windows, включая записи в Microsoft Store. ручной выбор файлов остается доступным.
- **Пользовательские действия:** запускать приложения, открывать папки или веб-сайты, отправлять ярлыки и контролировать носители.
- **Бесплатные ключи:** Сохраняйте F13-F24 доступным для ярлыков, настроенных непосредственно в игре или другом приложении.
- **Местные профили:** создавать, дублировать, переименовывать, удалять и выбирать профили. Калибровка распределяется между профилями.
- **Готовые профили:** Начните с шаблонов «Музыка», «Производительность» или «Создание», затем настройте их. Переключитесь на конкретный, следующий или предыдущий профиль из физического ключа.
- **Более быстрое редактирование:** Копировать/вырезать/вставить/перезагрузить полные клавиши, записать ярлыки клавиатуры, выбрать ключевые цвета акцента и отменить изменения.
- **Инструменты Windows:** Откройте звук, дисплей, Bluetooth и настройки сети, диспетчер задач или заблокируйте сеанс.
- **Компактный темный интерфейс:** векторные иконки, иконки приложений, где они доступны, и тонкие анимации, которые уважают предпочтения анимации Windows.
- **Справочная операция:** держать DeckPilot в области уведомлений, при запуске в Windows вход включен по умолчанию (можно отключить).
- **Автоматические обновления:** Утвердить новый релиз, затем разрешить DeckPilot загружать, проверять, заменять и перезапускать себя.

<a id="getting-started"></a>
## Начало работы

<a id="requirements"></a>
### Требования

- Windows 10 или Windows 11, **x64**.
- Совместимая с Arduino Leonardo макроплатформа 12 Отличительные ключи от **F13 до F24**.
- Подключение данных USB.

Опубликованные загрузки включают в себя время выполнения .NET. **Вам не нужно устанавливать .NET для использования DeckPilot.**

<a id="install-and-launch"></a>
### Установка и запуск

1. скачать **[DeckPilot-Setup.exe](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot-Setup.exe)** Windows запрашивает разрешение администратора для установки в **Файлы программы\DeckPilot**.
2. Инсталлятор добавляет DeckPilot В Windows **Установка приложений**, создает ярлык меню «Пуск» и по умолчанию выбирает ярлык рабочего стола и параметры запуска Windows. Вы можете отключить эти дополнительные задачи.
3. Подключите макропаду и откройте DeckPilot от его короткого пути.
4. Следуйте калибровке слева направо поперек **Четыре колонны**Затем следующий ряд, для **три ряда**Каждая кнопка должна посылать другой ключ F13-F24.

При переходе от прежнего 4- ровная планировка, DeckPilot сохраняет профили/действия и запрашивает одну новую калибровку для исправленных позиций.Установка поверх существующей портативной установки также сохраняет настройки в `%APPDATA%\DeckPilot`Оставьте старую копию, если настройка попросит вас.

портативный [DeckPilot.exe](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot.exe) и [ZIP](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot-win-x64.zip) Оставайтесь доступными для совместимости. Для портативного использования храните исполняемый файл в написанной личной папке.

Удалить из Windows **Установка приложений**Удаление удаляет программу и ее ярлыки, сохраняя при этом личные профили, чтобы более поздняя переустановка могла их повторно использовать.

Однофайловый исполняемый файл извлекает свои связанные зависимости в кэш .NET пользователя при первом запуске, что может занять немного больше времени. Опубликованные исполняемые файлы в настоящее время не подписаны, поэтому Windows может отображать предупреждение SmartScreen.

<a id="configure-a-key"></a>
### Настройка ключа

1. Выберите ключ в сетке
2. Выберите действие в правой боковой панели.
3. Настройка его настроек ниже сетки и сохранение. Переключение клавиш или профилей также сохраняет настройки текущего ключа.

| Меры | поведение |
| --- | --- |
| Бесплатный ключ | Пропускает F13-F24 в обычном режиме. Назначьте его непосредственно в своей игре или приложении. |
| Применение | Запускает установленное приложение или вручную выбранную программу или ярлык. |
| папка | Открывает папку в Windows Explorer. |
| Сайт | Открывает HTTP или HTTPS адрес в браузере по умолчанию. |
| ярлык клавишной клавиши | Отправляет комбинацию ключей в активное окно. |
| СМИ | Управляет воспроизведением, треками, громкостью или немым. |

Для действий приложения откройте выборщик приложения и поиск по имени. Селектор ручного файла остается доступным, с дополнительными аргументами программы по расширенным опциям. Введите аргументы в соответствии с синтаксисом целевого приложения.

Удержание кнопки запускает сконфигурированное действие только один раз до релиза.В режиме свободного ключа остаются доступны обычные повторные события клавиатуры.

<a id="manage-profiles"></a>
### Управление профилями

Откройте раздел управления профилем в правой боковой панели для создания, дублирования, переименования или удаления профиля. Используйте селектор над сеткой ключей для выбора активного профиля. Должен оставаться хотя бы один профиль.

Калибровка распространяется на все профили и может повторяться с боковой панели.

<a id="background-operation"></a>
### Справочная операция

Закрытие окна скрывает DeckPilot Двойной щелчок значка области уведомлений рядом с часами, чтобы снова открыть его, или щелчок правой кнопкой мыши значок и выбрать команду выхода, чтобы остановить его полностью.

Стартап Windows включен по умолчанию для текущего пользователя. Вы можете отключить его **Lancer avec Windows**; более поздние обновления приложений сохраняют этот выбор. Установка и последующие запуски обновляют включенный вход на текущий исполняемый путь.

<a id="installed-applications"></a>
## Установка приложений

Сборщик читает ярлыки из текущих пользовательских и общесистемных меню «Пуск», а затем дополняет их `Get-StartApps` Результаты из каталога приложений Windows.

Поиск игнорирует случай и акценты. Дублирующие имена сгруппированы, при этом в меню Пуск в приоритете. Портативные приложения и программы без зарегистрированных ярлыков по-прежнему можно выбирать вручную. Если каталог Windows недоступен, доступные для чтения ярлыки меню Пуск остаются пригодными для использования.

Windows запускает выбранные ярлыки. `shell:AppsFolder`Дополнительные аргументы применяются к файловым программам и ярлыкам; они скрыты для записей AppsFolder.

<a id="automatic-updates"></a>
## Автоматические обновления

Доступно с тех пор **0.2.0**Автоматические проверки обновлений выполняются при запуске после калибровки, затем каждые шесть часов. Их можно отключить в боковой панели. Остается ручная проверка.

Когда будет найден новый стабильный релиз GitHub, DeckPilot Спрашивается, обновляться ли. **Установленные копии** Скачать и SHA-256 проверять `DeckPilot-Setup.exe`, затем запустить установщик. Windows запрашивает у администратора разрешение на обновление файлов программы. DeckPilot изящно, когда готово, сохраняет профили и настройки запуска, устанавливает новую версию и перезапускает приложение. Отмена запроса разрешения Windows оставляет приложение открытым. Настройка отказывается прерывать открытую сессию прошивки.

**Портативные копии** Сохранить существующий механизм обновления. После подтверждения он:

1. Загружает исполняемый файл с отчетом о прогрессе и поддержкой отмены.
2. Проверить свой SHA-256 хеш против `SHA256SUMS.txt` В том же релизе GitHub.
3. Сохраните настройки и подготовьте помощника обновления.
4. Выходит, заменяет исполняемый и перезапускается.
5. Сохраняет предыдущий исполняемый файл до тех пор, пока новый процесс не подтвердит успешную инициализацию; если стартап терпит неудачу, он восстанавливает и перезапускает предыдущую версию.

Выбор обновления позже откладывает автоматические подсказки для 24 Ручные проверки обходят эту отсрочку.

Загрузки используют HTTPS с перенаправлениями, ограниченными ожидаемыми хостами GitHub.Временные файлы хранятся в `%LOCALAPPDATA%\DeckPilot\Updates`Загрузки старше семи дней очищаются. Запись запуска Windows продолжает использовать тот же исполняемый путь после обновления.

Портативные копии требуют написанной личной папки.Установленные копии используют установщик для защищенных каталогов; DeckPilot Само приложение продолжает работать без прав администратора.

**Модернизация от 0.1.х?** Бросьте старую версию из области уведомлений и вручную замените исполняемый файл последним релизом один раз. Эти старые версии не содержат обновителя. Более поздние обновления могут быть установлены изнутри DeckPilot.

<a id="settings-and-backups"></a>
## Настройки и резервные копии

Профили и калибровка хранятся вне папки приложения:

```text
%APPDATA%\DeckPilot\settings.json
```

Бросить DeckPilot перед копированием этого файла для резервного копирования или восстановления конфигурации. Если файл настроек не может быть прочитан, DeckPilot Сохраняет копию с `.backup-<date>` суффикс перед использованием новой конфигурации.

Обновление проверяет контакт с GitHub и может быть отключено в интерфейсе.

<a id="validation"></a>
### валидация

Консоль проверяет выход с ненулевым статусом по первому неудачному утверждению.

- Картирование ключей, повторы с удерживаемым ключом, релизы, переключение профиля и копирование действий.
- Проверка настроек, сохранение и миграция из старых конфигураций.
- Поиск приложений и обработка целей.
- Выбор выпуска, контрольные суммы, усеченные или поврежденные загрузки, перенаправления и отмена.
- Исполняемая замена, сохранение резервного копирования и откат.

Проверка блокировки файлов выполняется только в Windows.

Он также выполняет переименованные исполняемые файлы и пути, содержащие пробелы. Этот скрипт зарезервирован для одноразовой тестовой учетной записи GitHub Actions. CI также запускает `tests/windows-installer-smoke.ps1`Реальная установка файлов программы, ярлыки меню рабочего стола / запуска, запуск по умолчанию, обновление с открытым приложением, сохранение запуска с отключением и удаление без удаления профилей.

<a id="hardware-checks-on-windows"></a>
## Аппаратные проверки в Windows

С Леонардо связаны:

- калибровать все 12 позиции в произвольном порядке F13-F24. Подтвердить дублирование ключей отклоняется и отмена сохраняет прежнее отображение.
- Назначьте бесплатный ключ в игре и убедитесь, что игра получает его в обычном режиме.
- Запустите настроенную программу, затем удерживайте кнопку: она должна запускаться один раз до выпуска. Включите пути, содержащие пробелы и необязательные аргументы.
- Проверьте папку, веб-сайт, ярлык в обычном приложении и средства управления мультимедиа.
- Отправьте F13-F24 через ярлык действия и подтвердите, что нет петли DeckPilot действия.
- Создавайте два профиля с разными действиями, переключайтесь между ними, прекращайте и перезагружайте. Профили и калибровка должны сохраняться.
- Закройте окно, активируйте действие, затем снова откройте и прекратите через иконку области уведомлений. DeckPilot Выходы, все ключи должны проходить нормально.

<a id="current-limitations"></a>
## Существующие ограничения

- Прослушивание ключей является глобальным для сеанса Windows. Физические клавиши F13-F24 с другой клавиатуры следуют той же конфигурации. Вводимые программным обеспечением события клавиатуры игнорируются для предотвращения циклов действий.
- Некоторые игры, античитерские системы или программы, использующие прямой ввод устройства, могут по-прежнему получать перехваченные ключи. Доступен режим свободного ключа. Экран входа, безопасный рабочий стол и другие сеансы находятся вне контроля приложения.
- Windows может блокировать ярлыки, отправляемые в приложения, работающие с правами администратора. DeckPilot Работает без прав администратора и не обходит это ограничение.
- Выпустите Ctrl, Alt, Shift и Windows, прежде чем инициировать ярлык действия. Комбинации, такие как Alt+Tab, остаются предметом поведения Windows.
- Обнаружение отключений, автоматические профили в каждой игре и подписанный установщик - это будущие улучшения. Профили в настоящее время выбираются вручную.

История сохраняет отдельные снимки моделей, проверяет новые состояния и избегает анализа JSON во время отмены/редо. 50-ограничение редактирования и 20 Сохранились резервные копии профиля.

Поиск и сборщик делятся неизменяемым каталогом установленных приложений в течение пяти минут.15 секунды для частичного результата. Конкурентные потребители разделяют одно сканирование; закрытие одного пикера не отменяет другого потребителя. Обновление обходит кэш, и у каждого пикера есть свой фильтр/просмотр. Сканирование и анализ каталога стекают с потока пользовательского интерфейса; фильтрация пикера опровергается 120 Г-жа Action Search перепроверяет этот кэш после его опровержения и при возвращении из пикера, поэтому там также доступен обновленный каталог.

Обновления пользовательского интерфейса теперь следуют уведомлениям о подключении вместо пробуждения каждого 100 ms. Упорядоченные уведомления об отключении по-прежнему отменяют ожидающие трюмы. Клавишные крючки очередей визуальной работы, при этом подавление и синхронизация жестов остаются синхронными. Скрытые/минимизированные окна останавливают анимацию обратной связи и используют десятисекундный интервал аудио-опроса вместо двух секунд; немедленно открывают или выдают аудиокоманды запросов свежего состояния. В ожидании аудиообновления делят цикл и включают запросы, поступающие во время существующего чтения. Неизмененные аудиоснимки и замороженные кисти избегают повторных выделений пользовательского интерфейса. Процессные обертки, возвращаемые запуском приложения, утилизируются без закрытия запущенной программы.

Эти изменения уменьшают заданную работу; они не устанавливают машинно-независимый процент CPU/RAM. Нативное аппаратное переключение аудио и поведение физического ключа по-прежнему требуют проверки на ПК с Windows с макропадой.
