## おすすめ商品

- **ガイドされた口径測定:** 全てを識別 12 マクロパッドを再配線することなく、物理的なボタン。
- **インストールされたアプリケーションピッカー:** 検索 スタート メニュー ショートカットと Windows アプリケーション カタログ, 含む Microsoft Store エントリ. 手動ファイル選択は利用できます。.
- **カスタムアクション:** アプリケーションを起動し、フォルダまたはウェブサイトを開き、ショートカットを送信し、メディアをコントロールします。
- **未割り当てキー:** F13-F24 は、ゲームまたは別のアプリケーションで直接設定されたショートカットに使用できます。
- **ローカルプロフィール:** プロファイルを作成、複製、名前変更、削除、および選択します。 校正は、プロファイル間で共有されます。
- **既製のプロファイル:** 音楽、生産性、または作成テンプレートから始めて、それらをカスタマイズします。 物理的なキーから特定の、次または前のプロファイルに切り替えます。
- **より速い編集:** コピー/カット/ペースト/リセットキー、レコードキーボードショートカット、キーアクセントカラーを選択し、変更を解除します。
- **Windowsツール:** サウンド、ディスプレイ、Bluetooth、ネットワークの設定、タスクマネージャ、またはセッションをロックします。
- **密集した暗いインターフェイス:** ベクターアイコン、利用可能なアプリケーションアイコン、およびWindowsアニメーションの好みを尊重したアニメーションを微妙に表示します。

<a id="install-and-launch"></a>
### インストールと起動

1. ダウンロード **[DeckPilot-Setup.exe の設定](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot-Setup.exe)** インストーラーを実行します。 Windows は、インストールする管理者権限を要求します **Program Files\DeckPilot**.
2. インストーラは、あなたが選ぶことができます DeckPilot Windows で起動し、アプリの更新を自動的に確認し、アニメーションを削減します。 スタートアップとアップデートチェックはデフォルトでオンです。 アニメーションの縮小はオフです。 また、署名のチェックも行います VB-CABLE 必要な運転者 Soundboard 欠落した場合は、自動的にインストールします。そのドライバチェックにはインターネット接続が必要です。
3. インストーラーは追加します DeckPilot Windows に **インストールされたアプリ** [スタート]メニューのショートカットを作成します。デスクトップのショートカットはデフォルトで選択されます。
4. マクロパッドを接続し、開く DeckPilot ショートカットから。
5. 左から右にキャリブレーションを続けてください **4つのコラム**, 次の行, のために **3列**. 各ボタンは別のF13-F24のキーを送って下さい。

前者からアップグレードする場合 4-rowのレイアウト、 DeckPilot プロファイル/アクションを保存し、修正された位置の1つの新しい校正を要求します。 既存のポータブルセットアップにインストールしても、設定を保存します。 `%APPDATA%\DeckPilot`; セットアップがあなたに尋ねる場合は、古いコピーを終了します。

ポータブル [DeckPilot.exeについて](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot.exe) そして、 [ゼップ](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot-win-x64.zip) 互換性のために利用できます。 ポータブル使用のために、書き込み可能な個人的なフォルダで実行可能に保ちます。

Windowsからアンインストールする **インストールされたアプリ**. アンインストールは、プログラムとそのショートカットを削除し、個人的なプロファイルを保持しながら、後で再インストールして再利用することができます。

単一ファイル実行可能は、最初の起動時に、そのバンドルされた依存関係をユーザの .NET キャッシュに抽出します。これにより、少し長くなることができます。 公開された実行可能は、現在署名されていないため、Windows は SmartScreen 警告を表示できます。

<a id="configure-a-key"></a>
### キーの設定

1. グリッドのキーを選択します。
2. 右側のサイドバーのアクションを選択します。
3. グリッドの下の設定を構成し、保存します。キーまたはプロファイルの切り替えは、現在のキーの設定を保存します。

| アクション | ビーキャビター |
| --- | --- |
| 未割り当てキー | 通常通りF13-F24を渡します。ゲームやアプリケーションに直接割り当てます。 |
| 導入事例 | インストールされたアプリケーションまたは手動で選択したプログラムまたはショートカットを起動します。 |
| フォルダ | Windowsエクスプローラーのフォルダを開きます。 |
| サイトマップ | デフォルトブラウザでHTTPまたはHTTPSアドレスを開きます。 |
| キーボードショートカット | アクティブなウィンドウにキーの組み合わせを送信します。 |
| メディア | 再生、追跡、音量、またはミュートを制御します。 |
| スポット | Spotifyの再生をコントロールし、SpotifyのWindowsオーディオセッションボリュームのみを調整します。 |
| OBS / ストリームラボ | シーン、ライブ出力、録画、再生バッファ、オーディオミュート、ソースの可視性のためのアプリケーションのWebSocket APIに直接話します。 |
| アプリケーション — DeckPilot | 既存のものを表示する DeckPilot 通知領域で実行されるときを含むウィンドウ。 |

アプリケーションアクションの場合、アプリケーションピッカーを開き、名前で検索します。 手動ファイルセレクターは、オプションのプログラム引数を高度なオプションで利用できます。 ターゲットアプリケーションの構文に従って引数を入力します。

ボタンを押し続けると、設定されたアクションがリリースまで1回だけトリガーされます。フリーキーモードでは、通常のキーボードのリピートイベントが利用できなくなります。

<a id="manage-profiles"></a>
### プロファイルの管理

右側のサイドバーのプロファイル管理セクションを開き、プロファイルを作成、複製、名前変更、または削除します。 アクティブなプロファイルを選択するには、キーグリッド上のセレクターを使用してください。 少なくとも1つのプロファイルが残っている必要があります。
