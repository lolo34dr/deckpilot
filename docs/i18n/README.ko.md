DeckPilot 이미 보낼 Arduino Leonardo-compatible macropads 구성 **F13–F24(금)** USB 키보드 입력으로, 배열하는 **3 의 행 4 지원하다**. 육체적인 중요한 순서는 arbitrary일 수 있습니다: 그것의 위치에 가이드된 구경측정 지도 각 단추.

**추가 드라이버 또는 펌웨어 변경이 필요 없습니다.** 이 응용 프로그램은 현재 프랑스어입니다. 기술 참조 및 버전 역사를 포함하여 전체 번역 README에 대한 위의 언어를 선택하십시오. 번역은 자동으로 생성됩니다; 이 영어 원본은 참조입니다.

<a id="features"></a>
## 제품 설명

- **Guided 구경측정:** 모두 보기 12 당신의 macropad를 rewiring 없이 육체적인 단추.
- **설치된 신청 피커:** Microsoft Store 항목을 포함한 시작 메뉴 단축키 및 Windows 응용 카탈로그를 검색하십시오. 수동 파일 선택은 사용할 수 있습니다.
- **공급 능력:** 응용 프로그램, 열린 폴더 또는 웹 사이트, 단축키를 보내고, 미디어를 제어합니다.
- **무료 키:** F13–F24는 게임이나 다른 응용 프로그램에 직접 구성된 단축키에 사용할 수 있습니다.
- **현지 프로필:** create, duplicate, rename, delete, and select profiles. 교정은 프로파일을 통해 공유됩니다.
- **준비된 단면도:** Music, Productivity 또는 Creation Templates로 시작하면 사용자 정의 할 수 있습니다. 물리적 키에서 특정, 다음 또는 이전 프로파일로 전환하십시오.
- **빠른 편집:** 복사/cut/paste/reset 완전한 열쇠, 기록적인 키보드 단축키는, 열쇠 악센트 색깔을 선택하고, undo 변화합니다.
- **Windows 도구:** 사운드, 디스플레이, Bluetooth 및 네트워크 설정, 작업 관리자, 또는 세션을 잠그십시오.
- **조밀한 어두운 공용영역:** 벡터 아이콘, 사용 가능한 응용 아이콘 및 Windows 애니메이션 환경을 존중하는 미묘한 애니메이션.
- **배경 가동:** 제품 정보 DeckPilot 알림 영역에서, Windows sign-in에서 시작으로 기본적으로 활성화 (사용할 수 있음).
- **자동 업데이트:** 새 릴리스를 승인 한 다음 DeckPilot 다운로드, 확인, 교체 및 재시작.

이전에서 업그레이드 할 때 4- 줄 배치, DeckPilot 프로파일/actions를 보존하고 올바른 위치에 대한 하나의 새로운 캘리브레이션을 요청합니다. 기존의 휴대용 설정에 설치하면 설정이 보존됩니다. `%APPDATA%\DeckPilot`; 설정이 당신에게 묻는 경우 오래된 복사본을 종료합니다.

휴대용 [덱파이어.exe](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot.exe) · [₢ 킹](https://github.com/lolo34dr/deckpilot/releases/latest/download/DeckPilot-win-x64.zip) 호환성을 위해 사용할 수 있습니다. 휴대용 사용을 위해, writable 개인 폴더에서 실행할 수 있습니다.

## 설치 된 응용

Picker는 현재 사용자 및 시스템 전체 시작 메뉴에서 단축키를 읽습니다. 그런 다음 보충 교재 `Get-StartApps` Windows 응용 프로그램 카탈로그에서 결과.

검색은 사건과 악센트를 무시합니다. 중복 이름은 우선 순위를 가지고 시작 메뉴 항목과 함께 그룹화됩니다. 등록 된 단축키없이 휴대용 응용 프로그램과 프로그램은 여전히 수동으로 선택 될 수 있습니다. Windows 카탈로그가 사용되지 않은 경우, 읽기 쉬운 시작 메뉴 단축키는 유용하게 유지됩니다.

Windows가 선택한 단축키를 시작합니다. 카탈로그 항목 사용 `shell:AppsFolder`. 선택적인 인수는 파일 기반 프로그램 및 단축키에 적용합니다; 그들은 AppsFolder 항목에 숨겨져 있습니다. 목록 응용 프로그램을 실행하지 않습니다.

## 자동 업데이트

현재 위치 **0.2.0**, 자동 갱신 체크는 구경측정 후에 시작에서 실행합니다, 그 후에 매 6 시간. 그들은 sidebar에서 비활성화될 수 있습니다. 수동 체크는 유효합니다.

새로운 안정적인 GitHub 릴리스가 발견되면, DeckPilot 업데이트 여부를 묻습니다. **설치된 복사** 다운로드 및 SHA-256 인증 및 인증 `DeckPilot-Setup.exe`, 다음 설치 프로그램을 시작합니다. Windows는 관리자 권한에 대한 요청을 업데이트 프로그램 파일. 설치 프로그램은 닫습니다. DeckPilot 이 웹 사이트는 애플 리케이션에 전념. 우리는 정품 앱과 게임을 제공 할 목적으로이 사이트를 만들었습니다. 4AppsApk 최고의 안드로이드 애플 리케이션을위한 무료 APK 파일 다운로드 서비스, 계략.

**휴대용 사본** 기존 업데이트 메커니즘을 유지합니다. 확인 후, 그것은:

1. 진행 보고 및 취소 지원으로 실행할 수 있습니다.
2. SHA- 인증256 해시 에 대하여 `SHA256SUMS.txt` 같은 GitHub 릴리스에서.
3. 설정을 저장하고 업데이트 돕기를 준비합니다.
4. 종료, 실행을 대체하고, 재시작합니다.
5. 새로운 프로세스가 성공적인 초기화를 확인 할 때까지 이전 실행을 유지하십시오. 시작이 실패하면 이전 버전을 복원하고 다시 시작합니다.

나중에 업데이트하려면 자동 프롬프트를 postpones 24 시간. 수동 검사 bypass 그 postponement.

다운로드 사용 HTTPS, 예상 GitHub 호스트에 제한 된 리디렉션. 임시 파일은 저장 `%LOCALAPPDATA%\DeckPilot\Updates`; 7 일 이상 다운로드가 정리됩니다. Windows 시작 항목은 업데이트 후 동일한 실행 가능한 경로를 사용합니다.

휴대용 사본은 writable 개인적인 폴더를 요구합니다. 설치된 사본은 보호한 감독을 위한 installer를 이용합니다; DeckPilot 앱 자체는 관리자 권한없이 계속 실행됩니다.

**에서의 업그레이드 0.1.x는?** 알림 영역에서 이전 버전을 실행하고 수동으로 최신 릴리스를 한 번 실행할 수 있습니다. 이전 버전은 업데이 트를 포함하지 않습니다. 나중에 업데이트는 내부에서 설치할 수 있습니다. DeckPilot.

<a id="current-limitations"></a>
## 현재 제한

- 주요 청취는 Windows 세션에 글로벌입니다. 다른 키보드의 물리적 F13–F24 키는 동일한 구성을 따릅니다. 소프트웨어 주사 키보드 이벤트는 행동 루프를 방지하는 무시됩니다.
- 몇몇 게임, 반대로 cheat 체계, 또는 직접적인 장치 입력을 사용하는 프로그램 아직도 받아들인 열쇠를 받을지도 모릅니다. 자유로운 열쇠 형태는 유효합니다. 표시에서 스크린, 안전한 데스크탑 및 다른 회의는 신청의 통제 밖에 있습니다.
- Windows는 관리자 권한과 함께 실행되는 애플리케이션으로 단축키를 차단할 수 있습니다. DeckPilot 관리자 권한없이 실행하고이 제한을 우회하지 않습니다.
- Ctrl, Alt, Shift 및 Windows가 단축 작업을 트리거하기 전에 릴리스합니다. Alt+Tab과 같은 조합은 Windows 행동에 따라 남아 있습니다.
- Disconnect detection, 자동 per-game profiles, 그리고 서명된 installer는 미래 개선입니다. 단면도는 현재 수동으로 선정됩니다.

## 키패드 공용영역 (1.4.0)

더 큰 3 × 4 키패드는 물리적 인 인 인클로저와 블랙 키캡을 따릅니다. 각 키는 주요 아이콘, 라벨, F13-F24 매핑 및 작은 액션 유형 아이콘을 보여줍니다. 도구 팁은 전체 라벨과 위치를 유지합니다. 피드백, 실행 행동, 성공적인 파견 및 오류는 색상이 혼자서 상징을 포함하여 명백한 외관이 있습니다. 애니메이션은 Windows 애니메이션 선호를 따릅니다.

편집할 열쇠를 선택합니다. **Options avancées · fichier et arguments** 수동 응용 경로를 유지하고 기본으로 붕괴 된 인수를 시작합니다. 필수 폴더 및 웹 사이트 목적지가 확장되어 있습니다. 축소 설정은 값을 명확하지 않습니다. **Tester l’action** 현재 PC에서 선택한 작업을 저장하고 파견합니다. 성공 지표는 다른 응용 프로그램에 완료하지 않고 파견을 확인합니다. 키보드 단축키는 활성 창을 대상으로합니다. 무료 F13–F24 키에는 테스트 액션이 없습니다.

매크로패드가 분리되면, **Hors ligne** 힌트를 동반하면 프로파일이 여전히 편집 및 행동이 테스트 될 수 있음을 설명합니다. 구성은 PC에 저장되며 차단 및 재연결을 통해 사용할 수 있습니다. 이러한 인터페이스 개선은 기존 펌웨어와 함께 작동하며 추가 플래시가 필요하지 않습니다.

알림 영역 메뉴는 이제 프로파일을 직접 전환합니다. **Ctrl + S** 현재 버튼 구성을 저장합니다. 잘못된 구성 파일은 신선한 구성이 사용되기 전에 백업됩니다. 앱 설치, 데스크톱 / 시작 메뉴 아이콘, 시작 환경 설정 및 기존 자동 업데이트가 유지됩니다.

수동 Arduino IDE의 경우, **뚱 베어 DeckPilot 트레이 메뉴에서** 직렬 포트를 무료로합니다. 메인 창을 닫으면 배경에서 실행합니다.
