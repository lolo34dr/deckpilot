- يُطلق (إنسلر) (أتيلر) في دورة مستخدمي (ويندوز) المُوقّعة، ويتوقّف بأمان أو يُعيد تشغيله من أجل الترقية.
- (أتيلييه) يفحص (جيت هوب) عند بدء العمل وعند الطلب، ويعلن عن بناء (أتيلير) أو حزمة من البرمجيات، ثم يُحمّل مُحرّرًا مُحقّقًا من النشرة SHA-256 ملف
- البرمجيات الفيرمية لا تبث إلا بعد أن يختار المستعمل إجراء الوميض؛ ولا يكتب تحديث التذاكر أبداً إلى مجلس متصل بمفرده.
