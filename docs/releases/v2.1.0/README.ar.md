> هذه ترجمة تلقائية لمذكرات الإفراج الكامل، النسخة الأصلية الانكليزية هي المرجع.

DeckPilot 2.1.0 يُبقي الواجهة السوداء العميقة والألوان المُناسبة، ويُوجّهُ لوحة الصوت من خلال VB-Audio VB-CABLE ويختار المستعملون تلقائياً فقط ميكروفونهم الفيزيائي؛ ويُثبت نقطة النهاية الافتراضية بحيث لا يمكن إرسال مقاطع الصوت والصوت والأشعة فوق البنفسجية عن طريق الخطأ إلى المتكلمين. DeckPilot المُسلّح يستطيع تحميل المسؤول VB-CABLE حزمة، التحقق من ناشر أوثينتيكود، وإطلاق مجموعة سائقي البائع؛ والحزمة ليست إعادة توزيع. CABLE Output كميكروفون، (أتيلير) يبقى في نسخته 1.0.10.
