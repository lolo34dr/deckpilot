DeckPilot 2.1.9 Windows 오디오 형식이 확장 가능한 장치에서 스피커 모니터링을 수정하고 일부 USB 헤드셋을 포함하여 사운드 보드 오버레이 알림을 추가합니다.

- 스피커 리턴은 선택한 출력의 정확한 WASAPI 믹스 형식을 유지하고, PCM 또는 플로트 인코딩에 클립 샘플을 변환하고, 드라이버가 그 모드를 거부 할 때 이벤트 구동 재생없이 리리스를합니다.
- Soundboard 클립을 시작하면 설정 가능한 화면 오버레이의 이름을 보여줍니다. 기존 프로파일 알림 설정, 배치 및 축소 모션 설정 컨트롤 모두 알림 유형.
- 반환은 여전히 단지 사운드 보드 클립을 포함; 물리적 마이크는 스피커 믹스에서 유지하고 가상 마이크에 계속.

DeckPilot Atelier에 남아 있다 1.0.12 펌웨어가 남아 있습니다. 1.1.1. 굳힌모 섬광은 필요하지 않습니다. 스피커 겸용성은 소유자의 실제적인 Windows 오디오 장치로 아직도 검사되어야 합니다.
