DeckPilot 1.7.0 уменьшает многократную работу при редактировании профилей, поиске приложений и работе в фоновом режиме.

- Сохранение неизмененных настроек больше не заменяет файл или создает резервные копии. Фактическое содержимое диска все еще проверяется, поэтому внешние правки, удаления и неудавшиеся сохранения не скрыты.
- История профилей сохраняет отдельные снимки моделей. Неизмененные правки и отмена / отмена обходных путей JSON; редактирование действий использует сравнения значений вместо повторной сериализации.
- Поиск приложений и сборщик разделяют пятиминутный кэш каталога и одну задачу обнаружения. Discovery работает за пределами WPF; Refresh все еще заставляет новое сканирование. Каждый сборщик владеет своим фильтром и сохраняет текущие результаты, пригодные для использования во время обновления.
- Заменить постоянный 100 ms board UI poll with ordered connection notifications. Keyboard-hook callbacks queue visual work instead of rendering двенадцать клавиш синхронно.
- Опросы состояния аудио каждые две секунды, когда они видны, и каждые десять секунд, когда они скрыты/минимизированы, обновляются сразу после повторного открытия и после звуковых команд.
- Скрытые окна останавливают визуальные таймеры обратной связи и пропускают ожидания косметического рендеринга. Замороженные щетки пользовательского интерфейса повторно используются и запускаются обертки процесса приложения.

скачать **DeckPilot-Setup.exe** или обновление из приложения. Профили, калибровка и настройки запуска сохранены. Вспышка прошивки не требуется.

Валидация включает в себя регрессии настроек/истории/кэша и установку Windows, обновление, выборку, перетаскивание, редактирование коротких/длинных действий и минимизацию/восстановление проверок. Это структурные оптимизации, а не измеренное требование конкретного CPU или сохранения ОЗУ на каждом ПК.
