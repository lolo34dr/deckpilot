> 이것은 완전한 릴리스 노트의 자동 번역입니다. 영어 원본은 참조입니다.

DeckPilot 1.7.0 프로파일을 편집하고, 응용 프로그램을 찾고 배경에서 실행하는 동안 반복 작업을 감소시킵니다.

- 더 이상 변경되지 않는 설정을 저장하거나 백업을 생성합니다. 실제 디스크 내용이 여전히 체크되어 있으므로 외부 편집, 삭제 및 실패한 저장은 숨겨지지 않습니다.
- 프로파일 역사는 분리 된 모델 스냅 샷을 유지합니다. 변경되지 않은 편집 및 undo/redo는 JSON 라운드 스트립을 피합니다. 액션 편집은 반복 된 직렬화 대신 값 비교를 사용합니다.
- 응용 프로그램 검색 및 피커는 5 분 카탈로그 캐시와 하나의 발견 작업을 공유합니다. 디스커버리는 WPF 외부를 실행합니다. 여전히 새로운 스캔을 강제합니다. 각 피커는 필터를 소유하고 현재 결과를 새로 고침 중 유지합니다.
- 영원한 교체 100 ms board UI poll with order connection notifications. 키보드 후크 콜백 queue 시각적 작업 대신 렌더링 12 키 동시.
- 오디오 상태는 각 2 초마다 눈에 띄고 각 10 초마다 숨겨지은 / 분무, 오디오 명령 후에 즉시 상쾌하게 합니다. 과잉은 포스트 command 갱신을 떨어뜨리기 없이 탄화합니다.
- 숨겨지은 창 정지 시각적인 의견 타이머 및 건너뛰기 화장용 연출 기대. 언 UI 솔은 재사용되고 발사된 신청 과정 래퍼는 처분됩니다.

지원하다 **DeckPilot-설정.exe** 또는 앱에서 업데이트. 프로필, 교정 및 시작 환경 설정은 보존됩니다. 펌웨어 플래시가 필요하지 않습니다.

검증은 설정/history/cache 회귀와 Windows 설치, 업데이트, 피커, 드래그 앤 드롭, 단축 / 긴 작업 편집 및 최소화 / 복원 체크를 포함합니다. 이들은 모든 PC에서 특정 CPU 또는 RAM 절약의 측정 청구가 아닌 구조 최적화입니다.
