DeckPilot 2.3.0 Добавляет прямые элементы управления OBS Studio и Streamlabs Desktop из кнопок макропада.

- Подключайтесь к OBS через сервер WebSocket и Streamlabs Desktop через удаленное управление. DeckPilot Отправляет команды API приложения напрямую вместо имитации ярлыков клавиатуры.
- Настройка действий для сцен, прямой трансляции, записи, звукового отключения, видимости источника и буфера воспроизведения. OBS также поддерживает режим Studio Mode и управление виртуальной камерой.
- Потоковые учетные данные защищены для текущего пользователя Windows.Существующая прошивка макропада работает как есть; обновление прошивки или вспышка не требуется.
