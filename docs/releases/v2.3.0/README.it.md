DeckPilot 2.3.0 aggiunge controlli diretti OBS Studio e Streamlabs Desktop dai pulsanti macropad.

- Connettiti a OBS tramite il suo server WebSocket e Streamlabs Desktop tramite telecomando. DeckPilot invia i comandi API dell'applicazione direttamente invece di simulare le scorciatoie della tastiera.
- Configurare le azioni per scene, live streaming, registrazione, audio muto, visibilità sorgente e buffer replay. OBS supporta anche i controlli di Studio Mode e fotocamera virtuale.
- Le credenziali di streaming sono protette per l'utente corrente di Windows. Funziona il firmware della macropad così com'è; non è necessario alcun aggiornamento del firmware o flash.
