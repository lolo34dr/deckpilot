DeckPilot 2.3.0 adiciona controles diretos do OBS Studio e Streamlabs Desktop a partir de botões de macropad.

- Conecte-se ao OBS através de seu servidor WebSocket e Streamlabs Desktop através do controle remoto. DeckPilot envia comandos API de aplicação diretamente em vez de simular atalhos de teclado.
- Configure ações para cenas, streaming ao vivo, gravação, áudio mudo, visibilidade da fonte e buffer de repetição. OBS também suporta o modo de estúdio e controles de câmera virtual.
- As credenciais de streaming estão protegidas para o usuário atual do Windows. O firmware de macropad existente funciona como é; nenhuma atualização de firmware ou flash é necessária.
