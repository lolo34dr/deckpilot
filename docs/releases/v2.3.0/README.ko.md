DeckPilot 2.3.0 직접 OBS Studio 및 Streamlabs Desktop 컨트롤을 매크로패드 버튼에서 추가합니다.

- 원격 제어를 통해 WebSocket 서버와 Streamlabs 데스크톱을 통해 OBS에 연결하십시오. DeckPilot application API 명령어를 사용하여 키보드 단축키 대신 직접 명령을 보냅니다.
- 장면, 라이브 스트리밍, 녹음, 오디오 mute, 소스 가시성 및 재생 버퍼에 대한 작업을 구성합니다. OBS는 또한 스튜디오 모드와 가상 카메라 컨트롤을 지원합니다.
- 스트리밍 자격은 현재 Windows 사용자를 위해 보호됩니다. Existing macropad 펌웨어는 다음과 같이 작동합니다. 펌웨어 업데이트 또는 플래시가 필요하지 않습니다.
