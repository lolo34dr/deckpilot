DeckPilot 2.4.3 fügt dedizierte Deezer-Steuerelemente zur Makropad-Aktionsbibliothek hinzu.

- Weisen Sie Deezer Play/Pause, Next/Previous Track und Volume-Controls pro Anwendung zu.
- Deezer-Volume ändert nur seine Windows-Audiositzung in 5% Schritte; es ändert sich nie das Master-Volume oder eine andere App.
- Die Wiedergabesteuerung erfordert, dass die Deezer Windows-App eine Windows-Mediensitzung freigibt.
- Es ist kein Firmware-Update oder Flash erforderlich.
