DeckPilot 2.4.3 dodaje dedykowane sterowniki Deezer do biblioteki działań makro-pad.

- Przypisz grę / pauzę, następny / poprzedni tor i regulator głośności aplikacji do Deezer.
- Głośność deezera zmienia tylko sesję audio systemu Windows w 5% kroków; nigdy nie zmienia głównego wolumenu ani innej aplikacji.
- Kontrola odtwarzania wymaga, aby aplikacja Deezer Windows ujawniła sesję multimedialną systemu Windows. Odtwarzanie przeglądarki nie jest obsługiwane.
- Nie jest wymagana aktualizacja oprogramowania firmowego ani flash.
