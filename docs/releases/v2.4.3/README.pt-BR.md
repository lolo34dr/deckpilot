DeckPilot 2.4.3 adiciona controles Deezer dedicados à biblioteca de ação do macropad.

- Atribuir play/pause, próxima / anterior faixa e por aplicação controles de volume para Deezer.
- Volume Deezer muda apenas sua sessão de áudio Windows em 5% passos; ele nunca muda o volume mestre ou outro aplicativo.
- Os controles de reprodução requerem o aplicativo Deezer Windows para expor uma sessão de mídia do Windows. A reprodução do navegador não é suportada.
- Nenhuma atualização de firmware ou flash é necessária.
