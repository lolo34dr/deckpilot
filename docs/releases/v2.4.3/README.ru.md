DeckPilot 2.4.3 Добавляет выделенные элементы управления Deezer в библиотеку действий макропада.

- Назначьте игру / паузу, следующую / предыдущую дорожку и элементы управления громкостью для каждого приложения Deezer.
- Deezer изменяет только аудиосессию Windows 5% шагов; он никогда не изменяет основной объем или другое приложение.
- Элементы управления воспроизведением требуют, чтобы приложение Deezer Windows обнажило сеанс Windows Media. Воспроизведение браузера не поддерживается.
- Обновление прошивки или Flash не требуется.
