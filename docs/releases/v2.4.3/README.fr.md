DeckPilot 2.4.3 ajoute des commandes dédiées Deezer à la bibliothèque d'action macropad.

- Assignez le jeu/pause, la piste suivante/précédente et les commandes de volume par application à Deezer.
- Deezer volume ne change que sa session audio Windows dans 5% pas; il ne change jamais le volume principal ou une autre application.
- Les contrôles de lecture nécessitent l'application Deezer Windows pour exposer une session de médias Windows. La lecture du navigateur n'est pas prise en charge.
- Aucune mise à jour du firmware ou flash n'est nécessaire.
