Приложения installées, interface affinée et mises à jour automatiques.

- Sélecteur d'applications avec recherche par nom: menu Démarrer et catalog Windows/Microsoft Store. Le choix manuel d'un `.exe` Покой недопустим.
- Icônes des applications lorsqu'elles sont disponibles, pictogrammes vectoriels et animations discrètes respectant les préférences Windows.
- Recherche automationique des versions stables sur GitHub. Une confirmation suffit pour télécharger, vérifier, installer et redémarrer.
- Верификация SHA-256 et conservation de l'ancien exécutable jusqu'à confirmation du démarrage, avec restauration en cas d'échec.
- Profils et calibrage existants conservés.

**Депуи 0.1.x: quittez l'ancienne version près de l'horloge et remplacez l'exécutable une dernière fois manuellement.** Les mises à jour suivantes seront proposées automationiquement. Utilisez un dossier personnel modifiable pour permettre le remplacement.
