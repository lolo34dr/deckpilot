Applicazioni installées, interfaccia affinée et mises à jour automatiques.

- Sélecteur d’applicazioni avec recherche par nom: menu Démarrer et catalogo Windows/Microsoft Store. Le choix manuel d’un `.exe` rimanete indisponibili.
- Icônes des applicazioni lorsqu'elles sont disponibles, pittogrammes vectoriels et animazioni discrètes rispettoant les préférences Windows.
- Recherche automatique des version stables sur GitHub. Une conferma sufficiente per télécharger, vérifier, installer et redémarrer.

- Profils et calibrage existants conservés.

**Depuis 0.1.x: quittez l’ancienne versione près de l’horloge et remplacez l’exécutable une dernière fois manuellement.** Les mises à jour suivantes seront proposées automatiquement. Utilisez un dossier personal modifiable pour permettre le sostitument.
