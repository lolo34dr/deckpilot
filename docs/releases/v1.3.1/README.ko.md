DeckPilot 1.3.1 USB 연결을 개선하고 매크로패드 펌웨어를 검사합니다.

- 자동 재연결을 가진 연결 대쉬보드, 검출된 굳힌모, 살아있는 단추 state/USB 진단 및 몇몇 장치가 출석할 때 정당한 널 선택.
- 스타트업 펌웨어 검사 및 업데이트 제안, 와 24- 시간 알림 지연 및 펌웨어 알림 비활성화 옵션. 설치는 여전히 확인해야합니다.
- 새로운 펌웨어 **1.1.0**: 분산 프로토콜 메시지, 신선한 세션 토큰, 관련 심박수 응답 및 키 상태 이벤트. F13–F24 매핑은 독립 사용을 포함하여 변경되지 않습니다.
- 펌웨어 관리자는 식별 / 깜박임 및 다시 연결하기 전에 모니터의 직렬 포트를 자동으로 해제합니다. Firmware 1.0.0 그리고 레거시 정체 쿼리가 지원됩니다.
- 프로파일은 트레이 메뉴에서 선택할 수 있습니다. Ctrl + S는 변경 사항을 저장합니다. 연결 진단은 지원을 위해 복사 될 수 있습니다.

펌웨어 업데이트는 앱 릴리스에서 전달됩니다. 시작 체크는 포함 된 번들에 대한 감지 된 버전을 비교합니다. 하드웨어가 자동으로 깜박입니다. **회사 소개 1.1.0 여전히 첫 번째 물리적 보드 테스트가 필요합니다.** 펌웨어 1.0.0 그리고 이전 플래시 절차는 소유자에 의해 검증 된, 이 새로운 프로토콜은 호스트 테스트와 AVR 컴파일에 의해 덮여있다.

지원하다 **DeckPilot-설정.exe** 또는 앱에서 업데이트. 프로필, 교정 및 시작 환경 설정이 유지됩니다. Quit DeckPilot Arduino IDE 또는 다른 serial monitor를 사용하기 전에; in-app 펌웨어 관리자를 열어 연결이 자동으로 해제됩니다.
