- 응용 프로그램 실행 가능한 다중 해상도 Windows 아이콘을 포함 (16–256 px).

- 데스크톱 및 시작 메뉴 단축키 명시적으로 설치 DeckPilot 업그레이드를 포함한 아이콘.

지원하다 **DeckPilot-설정.exe** 기존 버전에 설치합니다. 프로필, 교정 및 시작 환경 설정이 유지됩니다. Firmware 1.0.0 변경되지 않습니다; 하드웨어 플래시가 필요하지 않습니다.
