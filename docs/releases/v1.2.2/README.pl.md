DeckPilot teraz wyświetla własne logo w systemie Windows zamiast ikony aplikacji ogólnej.

- Program wykonywalny osadza wielorozdzielczą ikonę Windows (16–256 px).
- Instalator i Windows odblokowują wpis używając logo projektu.
- Skróty w menu Desktop i Start wyraźnie odnoszą się do zainstalowanych DeckPilot ikonę, w tym na aktualizacjach.

Pobieranie **DeckPilot-Setup.exe** i zainstalować na istniejącej wersji. Preferencje profili, kalibracji i startup są przechowywane. 1.0.0 jest niezmieniony; nie jest potrzebny błysk sprzętowy.
