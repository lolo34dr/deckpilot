DeckPilot ora visualizza il proprio logo in Windows invece dell'icona generica dell'applicazione.

- L'applicazione eseguibile incorpora un'icona di Windows multi-risoluzione (16–256 px).
- L'installatore e la voce disinstallazione di Windows utilizzano il logo del progetto.
- Le scorciatoie del menu Desktop e Start richiamano esplicitamente l'installazione DeckPilot icona, inclusi gli aggiornamenti.

Scarica **DeckPilot-Setup.exe** e installare sulla versione esistente. Profili, preferenze di calibrazione e avvio vengono mantenuti. Firmware 1.0.0 è invariato; non è necessario alcun flash hardware.
