DeckPilot 2.1.5 сглаживает обновление аудиоустройства и добавляет фирменный экран запуска.

- Найдите физические микрофоны и VB-CABLE Автоматические повторы используют недавний снимок устройства; кнопка ручного обновления всегда выполняет свежее сканирование.
- Уменьшите количество повторных опросов Windows и оптимизируйте общий путь конверсии мономикрофона.
- Покажи. DeckPilot баннер при запуске интерактивного приложения. Молчаливый стартап с Windows остается на заднем плане.
- «Ателье» остается 1.0.11 Прошивка остается 1.1.1.

Валидация включает проверку регрессии фонового сканирования/кэша, проверку конверсии звука, сборки Windows, обновление/установку установщика, нативный всплеск/обновление и проверку приложений. Фактическое использование аудио процессора и задержка по-прежнему зависят от ПК и аудиоустройств.
