DeckPilot 2.4.8 Добавляет выделенное рабочее пространство для настройки одной или нескольких макропад.

- См. каждый обнаруженный макропад и его двенадцать клавиш на одной странице. Нажмите клавишу, чтобы назначить его действие, затем переключите устройства непосредственно из редактора.
- Дайте каждому макропаду свой профиль и калибровку. Существующие общие профили можно копировать без потери действий. Редактирование устройства сохраняет активный профиль клавиатуры F13-F24 на месте.
- Проверьте состояние каждого устройства и откройте его прошивку или элементы управления калибровкой от Macropads.
- Включает прошивку 1.2.0 Совместимые платы Leonardo и Pro Micro DeckPilot Режим USB отделяет вход USB от каждого устройства.Отдельный режим клавиатуры продолжает отправлять F13-F24.
