DeckPilot 2.4.8 Hinzufügen eines dedizierten Arbeitsbereichs zum Konfigurieren eines oder mehrerer Makropads.

- Sehen Sie sich jedes erkannte Makropad und seine zwölf Tasten auf derselben Seite an. Klicken Sie auf eine Taste, um seine Aktion zuzuweisen, und wechseln Sie dann die Geräte direkt aus dem Editor.
- Geben Sie jedem Makropad ein eigenes Profil und eine eigene Kalibrierung. Bestehende gemeinsame Profile können kopiert werden, ohne dass Aktionen verloren gehen. Das Bearbeiten eines Geräts hält das aktive F13-F24-Tastaturprofil an seinem Platz.
- Überprüfen Sie den Status jedes Geräts und öffnen Sie die Firmware oder die Kalibrierungssteuerelemente von Macropads.
- Enthält Firmware 1.2.0 für kompatible Leonardo und Pro Micro Boards. DeckPilot Der Modus trennt den USB-Eingang von jedem Gerät. Standalone-Tastaturmodus sendet weiterhin F13-F24.
