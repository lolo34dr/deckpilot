DeckPilot 2.4.8 dodaje dedykowaną przestrzeń roboczą do konfiguracji co najmniej jednego makro-padku.

- Zobacz każdy wykryty makro pad i jego dwanaście klawiszy na tej samej stronie. Kliknij klawisz, aby przypisać jego działanie, a następnie przełącz urządzenia bezpośrednio z edytora.
- Daj każdemu makro-pad swój własny profil i kalibrację. Istniejące wspólne profile mogą być kopiowane bez utraty akcji. Edycja urządzenia utrzymuje aktywny profil klawiatury F13- F24 na miejscu.
- Sprawdzić stan każdego urządzenia i otworzyć jego oprogramowanie firmowe lub kalibracyjne sterowniki z Macropads.
- Zawiera oprogramowanie firmowe 1.2.0 dla kompatybilnych desek Leonardo i Pro Micro. DeckPilot tryb oddziela wejście USB od każdego urządzenia. Tryb klawiatury standalone nadal wysyła F13- F24.
