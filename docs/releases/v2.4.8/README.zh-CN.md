DeckPilot 2.4.8 添加一个配置一个或多个宏板的专用工作空间。

- 在同一页上查看每个检测到的宏板及其十二个密钥。单击一个密钥来指定其动作,然后直接从编辑器切换设备。
- 给每个宏绘图器自己的配置和校准。 现有的共享配置文件可以复制而不会丢失动作。 编辑一个设备可以保持激活的 F13- F24 键盘配置文件 。
- 检查每个设备的状态,并从Macropads打开它的固件或校准控制器.
- 包括固件 1.2.0 为兼容的莱昂纳多和Pro微博板. DeckPilot 模式将 USB 输入从每个设备中分离。独立键盘模式继续发送 F13–F24。
