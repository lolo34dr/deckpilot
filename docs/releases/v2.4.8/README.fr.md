DeckPilot 2.4.8 ajoute un espace de travail dédié pour configurer un ou plusieurs macropads.

- Voir chaque macropad détecté et ses douze touches sur la même page. Cliquez sur une touche pour attribuer son action, puis basculez les périphériques directement à partir de l'éditeur.
- Donnez à chaque macropad son propre profil et calibrage. Les profils partagés existants peuvent être copiés sans perdre d'actions. La modification d'un appareil maintient le profil actif du clavier F13–F24 en place.
- Vérifiez l'état de chaque appareil et ouvrez son firmware ou ses commandes d'étalonnage à partir de Macropads.
- Comprend le firmware 1.2.0 pour les cartes Leonardo et Pro Micro compatibles. DeckPilot mode sépare l'entrée USB de chaque appareil. Le mode clavier autonome continue d'envoyer F13–F24.
