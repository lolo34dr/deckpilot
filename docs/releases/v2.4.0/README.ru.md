DeckPilot 2.4.0 Реорганизует панель управления и добавляет точный выбор цвета.

- Используйте **Меры**, **аптечка** и **Реглагес** вкладки для поиска ключевых действий, элементов управления устройством/аудио и предпочтений.
- Сохраняйте существующую левую клавиатуру / макет редактора, DeckPilot Логотип и монохромные векторные пиктограммы.
- Выберите точный фон, панель и акцент цвета с **Палетта...**, предварительно просмотреть их значения и часы, затем применить их. Сборщик Windows поддерживает пользовательские цвета; предварительно заданная тема не требуется.
- Удалить интеграцию управления OBS/Streamlabs. 2.3 Профили остаются читаемыми, и их отставные действия сохраняются, но не могут выполняться. Переназначьте эти ключи из библиотеки действий.
- Сохраняйте другие профили, действия и физическую калибровку. 1.1.1 «Ателье» остается 1.0.12; флэш-память не требуется.
