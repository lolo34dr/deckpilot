DeckPilot Теперь можно установить прошивку на DIY Pro Micro macropad прямо из приложения.

- Новый **Firmware du macropad…** диалог с выбором и подтверждением устройства перед миганием.
- Связанная прошивка **1.0.0** Сохраняет F13-F24 и добавляет DeckPilot Идентификационный/версионный ответ по USB-сериалу.
- Связанный AVRDUDE: нет установки Arduino IDE, необходимой для обычных обновлений.
- Проверенная контрольная сумма прошивки и границы памяти, физическое соответствие подключения USB, проверка записи и проверка версии после вспышки.
- Сохранены существующие профили и калибровка ПК. Обновление приложения никогда не мигает аппаратно автоматически.

**Первый аппаратный тест все еще требуется:** Подтверждена процедура загрузки исходной прошивки Caterina; новое прошивка / обновление все еще должно быть опробовано на фактической макропаде. **ATmega32U4, 5 В. 16 МГц**Проводник на **2–10, 14, 15, 16**, только с идентификаторами Leonardo USB и загрузчиком Caterina. Сохраните оригинальный эскиз и доступ к RST / GND для восстановления. Никакого резервного копирования прошивки или автоматического отката.

Windows 10/11 x64. Скачать **DeckPilot.exe** или **DeckPilot-win-x64.zip**Прошивка / инструменты встроены в приложение, а также доступны в **DeckPilot-firmware.zip**AVRDUDE имеет собственную лицензию GPL и комплектный источник.
