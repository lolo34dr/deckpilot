DeckPilot 1.6.1 фиксирует мягкий рендеринг клавиатуры и добавляет восстановление профиля, управление звуком Windows и короткие / длинные нажатия.

- Текст клавиатуры нативного размера: удалены эффекты масштабирования всей панели и тени контента, добавлена осведомленность о DPI на мониторе и более крупные значки настольных приложений. Маленькие окна прокручиваются вместо уменьшающихся клавиш.
- Undo/redo для редактирования профилей, включая drag-and-drop50 изменения за сеанс приложения; текстовые поля сохраняют нативный Ctrl+Z/Ctrl+Y.
- Профиль импорт/экспорт и 20 Автоматическое резервное копирование предыдущей версии. Импорт добавляет новые копии; восстановление и отмена калибровки. Импортные действия никогда не выполняются автоматически.
- Глобальный микрофон Windows переключается с постоянным индикатором строки состояния и статусом живой конечной точки. Все активные конечные точки захвата приглушены/неизменены вместе.
- Переключитесь между двумя выбранными подключенными устройствами вывода, для всех аудиоролей по умолчанию Windows. Пропущенные устройства выходят из строя, не выбирая бесшумно другой выход.
- Два сконфигурированных действия для ключа с 200–3000 Порог ms. Короткие запускаются при выпуске, длинные заменяют короткие и запускаются один раз. Существующие немедленные действия и бесплатные клавиши F13-F24 сохраняют свое поведение. Вспышка прошивки не требуется.

Состояние конечных точек Windows отличается от собственного немого приложения или аппаратного немого переключателя; приложения с фиксированным выходом могут не следовать за изменениями вывода по умолчанию.

Физические трюмы, фактические драйверы микрофона и переключение гарнитуры/ динамика по-прежнему нуждаются в подтверждении на оборудовании владельца.
