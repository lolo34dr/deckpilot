DeckPilot 1.6.1 naprawia miękkie renderowanie klawiatury i dodaje odzysk profilu, Sterowanie audio Windows i krótkie / długie prasy.

- Tekst klawiatury native- size: usunięto skalowanie całego pokładu i efekty cieni zawartości, dodano permonitor świadomości DPI i większe ikony aplikacji pulpitu. Małe okna przewijają się zamiast kurczących się klawiszy.
- Cofnij / powtórnie edytowanie profilu, w tym drag- and- drop (50 zmiany na sesję aplikacji); pola tekstowe utrzymują natywny Ctrl + Z / Ctrl + Y.
- Import / wywóz profilu oraz 20 Automatyczne tworzenie kopii zapasowych w wersji przedwczesnej. Importerzy dodają nowe kopie; przywracają i cofają kalibrację. Zaimportowane działania nigdy nie są wykonywane automatycznie.
- Globalny mikrofon Windows przełączał się z trwałym wskaźnikiem paska stanu i punktem końcowym na żywo. Wszystkie aktywne punkty końcowe przechwytywania są mutowane / odmutowane razem.
- Przełączanie pomiędzy dwoma połączonymi urządzeniami wyjściowymi dla wszystkich domyślnych ról audio systemu Windows. Brakujące urządzenia zawodzą bez cichego wybierania innego wyjścia.
- Dwie skonfigurowane akcje na klucz z 200–3000 Próg ms. Krótki bieg po wydaniu, długi zastępuje krótkie i działa raz. Istniejące natychmiastowe działania i wolne klawisze F13- F24 zachować ich zachowanie.

Pobieranie **DeckPilot-Setup.exe** lub aktualizacji z aplikacji. Profile i kalibracja są zachowane. Wybór punktu końcowego audio może wymagać dostosowania po importowaniu profili na innym komputerze PC. Stan końcowy systemu Windows różni się od własnego wyciszenia aplikacji lub sprzętowego wyłącznika wyciszenia; aplikacje fixed-output mogą nie śledzić domyślnych zmian wyjściowych.

Walidacja: profil podstawowy / testy gestu / audio (symulowane punkty końcowe audio), testy instalatora systemu Windows / update / UI, natywna edycja przesuwu myszy cofnij / redo i Long-action. Klucz fizyczny posiada, rzeczywiste sterowniki mikrofonu i słuchawki / przełączanie głośnika nadal wymaga potwierdzenia na sprzęcie właściciela.
