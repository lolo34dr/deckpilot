DeckPilot 2.1.7 Spotify-only 볼륨 작업을 추가, 내장 동작을 엽니 다 DeckPilot, 그리고 온-스크린 프로파일 알림.

- Spotify 볼륨 버튼은 Spotify의 Windows 오디오 세션을 조정합니다. 5마스터 볼륨 또는 다른 플레이어를 변경하지 않고 % 단계.

- 프로파일 변경은 활성 화면에 간단한, 비 활성화 오버레이를 보여줍니다. 선호도에 코너 또는 사용자 정의 위치를 선택하고 거기에 미리보기하십시오. 독점적 인 풀 스크린 게임은 표준 Windows 오버레이를 숨길 수 있습니다.
