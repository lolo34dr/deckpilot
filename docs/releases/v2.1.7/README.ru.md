DeckPilot 2.1.7 Добавляет Spotify-только объемные действия, встроенное действие для открытия DeckPilotи оповещения о профиле на экране.

- Кнопки громкости Spotify настраивают аудиосессию Windows в Spotify 5% шагов, без изменения мастер-объема или других игроков.
- Выборка приложений и поиск действий всегда предлагают DeckPilotи его действие показывает существующее окно из области уведомлений.
- Изменения профиля показывают краткое, неактивирующее наложение на активном экране. Выберите угловое или пользовательское положение в настройках и просмотрите его там. Эксклюзивные полноэкранные игры могут скрывать стандартные наложения Windows.

DeckPilot Ателье остается в 1.0.12 Прошивка остается 1.1.1Для этих действий не требуется вспышка прошивки.
