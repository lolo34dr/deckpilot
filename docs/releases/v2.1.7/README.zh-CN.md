DeckPilot 2.1.7 添加 Spotify- only 音量动作, 一个内置动作以打开 DeckPilot,以及屏幕上的配置图通知。

- Spotify 音量按钮在其中调整 Spotify 的 Windows 音频会话 5%步,不改变主音量或其他玩家.
- 应用程序拾取器和动作搜索总是提供 DeckPilot,其行动将显示来自通知区域的现有窗口。
- 配置文件更改显示在活动屏幕上有一个简短的、非激活的覆盖。 在首选项中选择一个角位置或自定义位置并在那里预览。 独家的全屏幕游戏可以隐藏标准的 Windows 覆盖 。

DeckPilot Atellier 仍为 1.0.12 和坚固的遗物 1.1.1。这些操作不需要硬软件闪光。
