- 작업을 위한 별도의 탭을 사용하여, 매크로패드, 오디오 및 설정. 헤더는 연결 상태와 기존을 보여줍니다. 3 × 4 keypad는 외관과 행동을 유지합니다.

- 어두운 테마에 체크 박스와 도구 팁을 읽고, 그들의 라벨 옆에 오디오 값을 볼 수 있습니다.
