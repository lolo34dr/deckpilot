DeckPilot 1.4.0 rafraîchit l'interface du clavier autour des casquettes noires du macropad physique.

- Plus grandes 3 × 4  touches dans une enceinte sombre, avec un 36  icône px, une étiquette courte, une légende F13–F24 et une petite icône de type action. Les étiquettes complètes restent disponibles en tooltips.
-  Commentaires indépendants pour les presses physiques, les actions en cours, l'expédition réussie et les erreurs. Les animations subtiles respectent le paramètre d'animation de Windows; les erreurs incluent une explication dans l'éditeur.
- A **Tester l’action**  bouton enregistre et exécute l'action sélectionnée sur le PC, y compris sans carte connectée. Un indicateur de succès signifie que l'action a été envoyée, et non que l'application lancée a terminé son travail.
- Les chemins d'application et les arguments manuels sont regroupés sous les options avancées effondrées. Les destinations du dossier et du site web restent élargies. Les préférences de l'application sont également effondrées par défaut.
- Le clavier affiche clairement son état de connexion et explique que les profils restent modifiables et les actions testables hors ligne.

 Télécharger **DeckPilot-Setup.exe** ou mise à jour depuis l'application. Profils, étalonnage et préférences de démarrage sont conservés. **1.1.1**; aucun nouveau flash de firmware n'est nécessaire pour les changements d'interface. 1.1.1  doit encore être validé sur le plan physique; le précédent 1.0.0 firmware et la procédure de clignotement ont été confirmés par le propriétaire.
