DeckPilot 1.5.0 ويضيف ضوابط محددة، والبحث عن العمل، والسحب والجرع، ويصلح تسجيل بدء تشغيل النوافذ.

- البحث والتطبيقات المركّبة بالاسم أو الكلمات الرئيسية مثل الحجم أو التفوّق أو التبريد أو التشويش أو النقر
- (دراغ) أعمال الكتالوج/البحث على المفاتيح، مبادلة اثنين من أعمال المفاتيح دون تغيير المعايرة، أو إسقاط وصلة قابلة للتنفيذ، أو مختصرة، أو مطوّرة، أو مطوّرة، أو هي تي بي.
- ويحتفظ البدء بتفضيل منقذ للمستعمل الواحد، ويصلح المسارات المفقودة/الثابتة، ويكشف عن أعلام ويندوز المعروفة التي لا يمكن تغييرها، ويدعم عملية إعادة تنشيط صريحة، ولا تزال عمليات إطلاق المعلومات الأساسية والمضاعفة صامتة، بما في ذلك قبل معايرة.
