DeckPilot 1.5.0 dodaje sterowania specyficzne Spotify, wyszukiwania akcji i drag- and- drop, i naprawy rejestracji startup systemu Windows.

- **Spotify** play / pauza, następny i poprzedni adres tylko sesja Spotify desktop media, utrzymując przeglądarkę / odtwarzanie YouTube oddzielnie. Otwórz Spotify i uruchom odtwarzanie raz. Spotify w przeglądarce nie jest obsługiwane; nie ma odwrotu global- media jeśli Spotify brakuje lub odmawia polecenia.
- Szukaj akcji i zainstalowanych aplikacji po nazwie lub słów kluczowych, takich jak volume, skip, Spotify lub Discord. Kliknij wyniki lub przeciągnij je na klucz.
- Przeciągnij działania katalogu / wyszukiwania na klawisze, zamień działania dwóch kluczy bez zmiany kalibracji, lub upuść wykonywalny, skrót, folder lub łącze HTTP (S). Drops skonfiguruje działania bez ich uruchamiania.
- Startup zachowuje zapisaną preferencję użytkownika, naprawia brakujące / nieaktualne ścieżki, wykrywa znane flagi wyłączenia systemu Windows i obsługuje wyraźną reaktywację. Tło i duplikaty startowe pozostają ciche, w tym przed kalibracją.

Build wymaga Windows 10 wersja 2004 lub później, lub Windows 11Pobieranie **DeckPilot-Setup.exe** lub aktualizacji z DeckPilot. Profile i kalibracja są zachowane; nie jest potrzebny błysk firmware. Aby naprawić wcześniej zablokowany startup, sprawdź jego status pod **Préférences de l’application** i włączyć **Lancer avec Windows** Jeszcze raz.

Walidacja obejmuje symulowaną izolację Spotify / przeglądarki, wyszukiwanie i sprawdzanie ustawień, testy naprawy instalatora systemu Windows / startup, prawdziwe pobieranie mysz i drop oraz natywną aktualizację / sprawdzanie interfejsu użytkownika. Spotyfikacja odtwarzania obok YouTube i prawdziwy sygnał systemu Windows nadal wymaga potwierdzenia na komputerze użytkownika.
