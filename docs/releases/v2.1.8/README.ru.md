DeckPilot 2.1.8 Добавлено дополнительное возвращение спикера для Soundboard Клипы.

- в **Soundboard · micro virtuel**позволяет **Исполнитель: Entendre aussi les sons du soundboard**Выберите физический динамик или выход гарнитуры и установите его независимое 0–100Отдача выключается по умолчанию и сохраняется при запуске.
- На этот второй выход отправляются только клипы на саундборде. Физический микрофон продолжает идти на виртуальный микрофон и никогда не смешивается с динамиком. Клипы все еще идут на VB-CABLE в их первоначальном объеме.
- Изменение громкости возврата не перезагружает виртуальный микрофон. Отключенный выход динамика останавливает только возврат; виртуальный микрофон продолжает работать. Обновите устройства или выберите другой выход для его восстановления.

DeckPilot Ателье остается в 1.0.12 Прошивка остается 1.1.1.Вспышка прошивки не требуется. Фактическая маршрутизация динамиков должна проверяться на ПК владельца Windows с его аудиоустройствами.
