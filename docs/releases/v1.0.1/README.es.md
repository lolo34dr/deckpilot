> Esta es una traducción automática de las notas de liberación completas. El original inglés es la referencia.

Preparación del renombre del repositorio: `streamdeck-diy` → `deckpilot`.

- Los cheques de actualización soportan los nombres de los repositorios, antes y después del renombre.
- La validación de descarga acepta sólo las rutas exactas de activos de liberación pertenecientes a estos dos repositorios.
- Los perfiles, la calibración y las acciones de aplicación no cambian.

**Instala esta versión antes de renombrar el repositorio GitHub.** Versiones 0.2.0 y 1.0.0 validar el nombre original del repositorio estrictamente y puede requerir una actualización manual si el repositorio ya ha sido renombrado.

Windows 10/11 x64. Descargar **DeckPilot.exe** o **DeckPilot-win-x64.zip**. Las actualizaciones permanecen disponibles dentro de la aplicación, mientras que el nombre original del repositorio está activo.
