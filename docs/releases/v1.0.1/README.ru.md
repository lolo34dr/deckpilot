> Это автоматический перевод полного выпуска примечаний. Английский оригинал - ссылка.

Репозиторий переименовывает подготовку: `streamdeck-diy` → `deckpilot`.

- Проверки обновлений поддерживают как имена репозиториев, до и после переименования.
- Валидация загрузки принимает только точные пути релиза, принадлежащие этим двум репозиториям.
- Профили, калибровка и действия приложения неизменны.

**Установите эту версию перед переименованием репозитория GitHub.** Версии 0.2.0 и 1.0.0 Строго проверяйте оригинальное имя репозитория и может потребоваться ручное обновление, если репозиторий уже был переименован.

Windows 10/11 x64. Скачать **DeckPilot.exe** или **DeckPilot-win-x64.zip**Обновления остаются доступными внутри приложения, в то время как оригинальное имя репозитория является активным.
