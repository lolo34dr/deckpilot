> Il s'agit d'une traduction automatique des notes de sortie complètes. L'original anglais est la référence.

 Préparation du nom du dépôt : `streamdeck-diy` → `deckpilot`.

- Les vérifications de mise à jour prennent en charge les deux noms de dépôt, avant et après le renommer.
-  Télécharger la validation accepte seulement les chemins exacts d'actifs de libération appartenant à ces deux dépôts.
- Les profils, l'étalonnage et les actions d'application sont inchangés.

**Installez cette version avant de renommer le dépôt GitHub.**  Versions 0.2.0 et 1.0.0  valider strictement le nom du dépôt original et peut nécessiter une mise à jour manuelle si le dépôt a déjà été renommé.

Windows 10/11 x64. Télécharger **DeckPilot.exe** ou **DeckPilot-win-x64.zip**. Les mises à jour restent disponibles dans l'application alors que le nom du dépôt original est actif.
