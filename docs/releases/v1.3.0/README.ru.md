DeckPilot 1.3.0 Улучшает соединение USB и проверяет прошивку макропада при запуске.

- Панель управления подключением с автоматическим переподключением, обнаруженной прошивкой, диагностикой состояния кнопки / USB и явным выбором платы при наличии нескольких устройств.
- Стартап прошивки проверки и обновления предложений, с 24- часовая задержка напоминания и возможность отключения уведомлений прошивки. Установка все еще нуждается в подтверждении.
- Новая прошивка **1.1.0**Ограниченные протокольные сообщения, новые сессионные токены, коррелированные ответы на сердцебиение и ключевые события. Картирование F13-F24 остается неизменным, включая автономное использование.
- Менеджер прошивки автоматически выпускает последовательный порт монитора перед идентификацией/вспышкой и повторно подключается после этого. 1.0.0 Идентификационные запросы остаются поддерживаемыми.
- Профили могут быть выбраны из меню лотка; Ctrl + S сохраняет изменения; диагностика соединения может быть скопирована для поддержки.

Обновления прошивки поставляются в выпусках приложений; проверки запуска сравнивают обнаруженную версию с включенным пакетом.
