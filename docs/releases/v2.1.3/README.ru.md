DeckPilot 2.1.3 Уменьшает задержку микрофона на звуковой панели и удаляет односекундные блоки преобразования с пути воспроизведения звука в реальном времени.

- Используйте выходную, мелкоблоковую повторную выборку для микрофона и звуковых клипов; соответствие частот выборки полностью обходит повторную выборку.
- Запрос событийный 20 ms захват и 40 Ms плейбэк буферы вместо предыдущих 100 фактическая задержка зависит от Windows, аудиоустройств и VB-CABLE.
- Связанный микрофон буферизация к 100 ms и сохраняют последние полные кадры после стойки воспроизведения вместо очередей старой речи. Короткие отрывки добавляют только тишину, требуемую текущим прочтением.
- Поддержка моно, стерео, многоканальных и расширяемых PCM/float вводов Windows без поддержки Media Foundation.
- Сохраняйте обработку и маршрутизацию Discord без изменений. 1.0.11 Прошивка остается 1.1.1.

Валидация включает в себя регрессионные проверки для повторного отбора размеров блоков, конверсии каналов, расширяемых форматов, восстановления под загрузкой, свежести переполнения, одновременного захвата / воспроизведения и завершения клипа, наряду с существующим установщиком Windows и тестами приложений. Ни один аппаратный показатель задержки не требуется; проверьте улучшение с помощью микрофона и аудио драйвера.
