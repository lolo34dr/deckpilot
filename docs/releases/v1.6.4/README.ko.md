DeckPilot 1.6.4 드래그 앤 드롭에서 검색-result 교체를 수정하고 Windows 검증을 안정화합니다.

- debounce timer 또는 install-app 카탈로그가 동일한 결과를 생성 할 때 기존 검색 버튼을 유지하므로 드래그 소스는 예기치 않게 분리되지 않습니다.
- 마우스 상호 작용 또는 OLE 드래그가 진행중인 동안 Defer search-result 교체.
- Windows UI는 물리적 커서 좌표를 사용하여 측정하기 전에 초점 컨트롤을 확인하고 라인 증가의 고정 수를 추측하는 대신 전체 스크롤 범위를 스캔합니다. 기본 마우스 드래그는 필수 유지; 실패 할당은 패스를 얻기 위해 검색되지 않습니다.
- Windows 설정은 전용 원자 교체 API를 사용하므로 기존 리더는 다음의 저장을 차단하지 않고 오래된 스냅 샷을 유지할 수 있습니다. 핵심 회귀는 공유 리더가 열린 3 개의 성공적 교체를 보장합니다.
- Windows 테스트에서 설정 리더 UTF-8 그리고 atomic 파일 교체를 허용한다. Snapshot 오프닝은 최대 기다립니다 500 교체 중에 Windows 공유 / 잠금 위반에만 ms; 다른 읽기 오류 및 지속적 잠금은 테스트 실패. 세 undo / redo 사이클은 기존 독자를 수정하지 않고 성공을 저장하기 위해 오래된 스냅 샷을 계속 유지.
- 배경-startup 체크는 WPF를 위해 그것의 창을 숨기고, 그 후에 눈에 보이는 주요 창으로 달리기 위하여 과정을 요구합니다.
