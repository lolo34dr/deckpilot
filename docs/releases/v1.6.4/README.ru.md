DeckPilot 1.6.4 исправляет замену результатов поиска во время перетаскивания и стабилизирует верификацию Windows.

- Сохраняйте существующие кнопки поиска, когда дебюнкционный таймер или каталог установленных приложений дает те же результаты, поэтому источник перетаскивания не отключается неожиданно.
- Замена результатов поиска в то время как взаимодействие с мышью или сопротивление OLE продолжается.
- Проверки пользовательского интерфейса Windows используют физические координаты курсора, элементы управления фокусировкой перед их измерением и сканируют полный диапазон прокрутки вместо того, чтобы предполагать фиксированное количество линейных приращений. Для получения пропуска требуются нативные перетаскивания мыши; неудавшиеся задания не перепроверяются.
- Настройки Windows сохраняют использование выделенного API атомной замены, чтобы существующий считыватель мог сохранить свой старый снимок без блокировки следующего сохранения. Ядро регрессии проверяет три последовательных замены с общим считывателем, удерживаемым открытым.
- Читатели настроек в тестах Windows используют UTF-8 и разрешить замену атомного файла. Открытие снимка ждет 500 ms только для нарушений обмена / блокировки Windows во время замены; другие ошибки чтения и постоянные блокировки не справляются с тестом. Три цикла отмены / восстановления также сохраняют старый снимок открытым для проверки того, что сохраняет успех без изменения существующих считывателей.
- Проверки фонового запуска ждут, пока WPF закончит скрывать свое окно, а затем требуют, чтобы процесс продолжал работать без видимого главного окна.
- Обновление GitHub Actions до Node.js 24 Версии и установка того же Arduino CLI 1.2.2 из его проверенного контрольной суммой архива.

скачать **DeckPilot-Setup.exe** или обновление из приложения. Профили и калибровка сохранены. Вспышка прошивки не требуется.
