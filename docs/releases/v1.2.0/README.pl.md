DeckPilot teraz instaluje jak zwykła aplikacja Windows, z poprawną **3 wiersze × 4 kolumny** układ makro-pad.

- Pobieranie **DeckPilot-Setup.exe** do instalacji **Program Files\DeckPilot**, z menu Start i skróty pulpitu i wpis z systemem Windows dezaktywowane.
- Uruchomienie systemu Windows jest domyślnie włączone i może być wyłączone podczas instalacji lub z aplikacji. Aktualizacje zachowują ten wybór.
- Instalowane aktualizacje aplikacji pobrać i zweryfikować pakiet konfiguracji, poprosić o normalne uprawnienia administratora systemu Windows, a następnie zainstalować i ponownie uruchomić aplikację.
- Główna siatka, etykiety pozycji i kalibracja z przewodnikiem używają teraz trzech rzędów czterech klawiszy. Istniejące profile / działania są zachowane; poprzedni układ wymaga nowej kalibracji.
- Oprogramowanie firmowe 1.0.0 nie zmienia się. Właściciel potwierdził udane migotanie, identyfikację wersji i wszystkie 12 klawiszy na makro-pad referencyjny. Ta aktualizacja aplikacji nie świeci sprzętem.

Okna 10/11 x64. Samotność **DeckPilot.exe** i przenośne ZIP pozostają dostępne dla starszych kompatybilności updater. Profile osobiste pozostają w `%APPDATA%\DeckPilot` i są przechowywane po odinstalowaniu.
