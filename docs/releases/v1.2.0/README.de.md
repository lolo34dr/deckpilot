- Download **DeckPilotSetup.exe** zu installieren in **Program Files\DeckPilot**, mit Startmenü und Desktop-Verknüpfungen und einem Windows-Deinstallationseintrag.

- Das Hauptraster, die Positionsetiketten und die geführte Kalibrierung verwenden nun drei Zeilen mit vier Tasten. Bestehende Profile/Aktionen werden beibehalten; das bisherige Layout erfordert eine neue Kalibrierung.
