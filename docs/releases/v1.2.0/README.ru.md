DeckPilot теперь устанавливается как обычное приложение Windows, с правильным **3 ряды × 4 колонны** Макропадная компоновка.

- скачать **DeckPilot-Setup.exe** Для установки в **Program Files\DeckPilot**, с меню «Пуск» и ярлыками рабочего стола и записью удаления Windows.
- Стартап Windows включен по умолчанию и может быть отключен во время установки или из приложения.
- Установленные обновления приложений загружают и проверяют пакет настроек, запрашивают обычное разрешение администратора Windows, затем устанавливают и перезагружают приложение.
- Основная сетка, позиционные метки и управляемая калибровка теперь используют три ряда по четыре клавиши.Существующие профили/действия сохраняются; предыдущая компоновка требует одной новой калибровки.
- Прошивка 1.0.0 Владелец подтвердил успешную вспышку, идентификацию версии и все двенадцать клавиш на эталонной макропаде. Это обновление приложения не вспыхивает аппаратным обеспечением.

Windows 10/11 x64 - автономный **DeckPilot.exe** Портативный ZIP остается доступным для более старой совместимости с обновлениями. `%APPDATA%\DeckPilot` и удерживаются на удалении.
