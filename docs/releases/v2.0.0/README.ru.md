DeckPilot 2.0.0 Новый саундборд принимает клипы MP3/WAV, позволяет пользователям выбирать физический микрофон и выход виртуального кабеля, а также смешивает голос с клипами для использования в качестве микрофона в играх или вызовах. Клипы можно запускать из приложения или назначать на клавишу макропада. Виртуальный аудиокабель, такой как VB-CABLE должна быть установлена отдельно на Windows; Atelier остается на версии 1.0.10.
