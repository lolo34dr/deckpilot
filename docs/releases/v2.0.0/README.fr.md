> Il s'agit d'une traduction automatique des notes de sortie complètes. L'original anglais est la référence.

DeckPilot 2.0.0 introduit une interface noire profonde avec fond, panneau et couleurs d'accent sauvegardés. La nouvelle carte son accepte les clips MP3/WAV, permet aux utilisateurs de choisir un microphone physique et une sortie de câble virtuel, et mélange la voix avec des clips pour l'utilisation comme microphone dans les jeux ou les appels. VB-CABLE doit être installé séparément sur Windows; Atelier reste à la version 1.0.10.
