> Il s'agit d'une traduction automatique des notes de sortie complètes. L'original anglais est la référence.

DeckPilot 2.0.0 Le nouveau tableau de son accepte les clips MP3/WAV, permet aux utilisateurs de choisir un microphone physique et une sortie de câble virtuel, et mélange la voix avec des clips pour l'utilisation comme microphone dans les jeux ou les appels. Les clips peuvent être lancés depuis l'application ou assignés à une touche macropad. Un câble audio virtuel tel que VB-CABLE doit être installé séparément sur Windows; Atelier reste à la version 1.0.10.
