DeckPilot 2.4.6 utrzymuje nowe klipy płyt dźwiękowych w DeckPilotwłasne przechowywanie i poprawia niezawodność profilu, mediów i makropadów.

- Dodawanie lub wymiana MP3 lub WAV teraz kopiuje plik do `%APPDATA%\DeckPilot\Sounds`. Odtwarzanie nadal działa, jeśli oryginał jest przesunięty lub usunięty. Aby skopiować istniejący klip, wybierz jego plik ponownie poprzez klip **…** menu.
- Import nieudanego profilu pozostawia aktywną konfigurację nienaruszoną. Powtórzone importowane ponowne użycie pasujące audio, a automatyczne kopie zapasowe pozostają w granicach pakietu, pomijając audio, które nie pasuje.
- Szybkie zmiany głośności Spotify i Deezer są stosowane w kolejności. Szablon muzyczny zawiera teraz grę / pauzę Deezer.
- DeckPilot Atelier 1.0.13 utrzymuje reagujący interfejs podczas operacji sprzętowych, dopasowuje odzysk do oryginalnego portu USB i sprawdza, czy Windows otrzymuje każde zdarzenie kluczowe.
- Opcjonalne oprogramowanie firmowe 1.1.2 wszystkie sprawozdania 12 F13- F24 klucze niezależnie. Instalacja aktualizacji systemu Windows nie wyświetla podłączonego makra.
