DeckPilot 2.4.6 mantém novos clipes de placa de som DeckPiloto próprio armazenamento e melhora a confiabilidade do perfil, mídia e macropad.

- Adicionando ou substituindo um MP3 ou WAV agora copia o arquivo para `%APPDATA%\DeckPilot\Sounds`. Playback ainda funciona se o original é movido ou excluído. Para copiar um clipe existente, selecione seu arquivo novamente através do clipe **…** menu.
- Importações de perfil falhadas deixam a configuração ativa intacta. Importações repetidas reutilizam o áudio correspondente, e backups automáticos permanecem dentro do limite do pacote omitindo áudio que não se encaixa.
- Rapid Spotify e Deezer alterações de volume são aplicadas em ordem. O modelo de música agora inclui Deezer jogar / pausa.
- DeckPilot Atelier 1.0.13 mantém a interface responsiva durante as operações de hardware, corresponde à recuperação para a porta USB original e verifica que o Windows recebe cada evento chave.
- firmware opcional 1.1.2 reporta tudo 12 F13-F24 chaves independentemente. Instalar a atualização do Windows não flash um macropad conectado.
