DeckPilot 2.4.6 새로운 Soundboard 클립을 유지 DeckPilot자체 저장 및 프로파일, 미디어 및 매크로 패드 신뢰성 향상.

- MP3 또는 WAV를 추가하거나 교체하기 위해 파일을 복사합니다. `%APPDATA%\DeckPilot\Sounds`. 재생은 여전히 원본이 이동되거나 삭제되는 경우에 작동합니다. 기존의 클립을 복사하려면 클립을 통해 다시 파일을 선택하십시오. **…** 메뉴입니다.
- Failed 프로파일 가져 오기는 활성 구성 intact를 남깁니다. 반복 된 수입은 오디오 일치를 재사용하고 자동 백업은 적합하지 않는 오디오를 omitting하여 패키지 제한 내에서 유지됩니다.
- Rapid Spotify 및 Deezer 볼륨 변경은 순서대로 적용됩니다. 음악 템플릿은 이제 Deezer Play/pause가 포함되어 있습니다.
- DeckPilot Atelier, 그리스 1.0.13 하드웨어 작업 중의 인터페이스 응답을 유지하고, 원래 USB 포트에 복구를 일치하고 Windows가 각 키 이벤트를받습니다.
- 옵션 펌웨어 1.1.2 모두 보기 12 F13–F24 키는 독립적으로. Windows 업데이트 설치는 연결된 매크로 패드를 플래시하지 않습니다.
