DeckPilot 2.4.2 ulepsza panel sterowania i utrzymuje działania edytorskie na widoku.

- Zachowaj **Tester** oraz **Enregistrer** obok wybranego klucza, więc pozostają one widoczne bez przewijania edytora.
- Zachowaj istniejący DeckPilot keypad workspace i jego oryginalna ciemna paleta przy jednoczesnym uproszczeniu biblioteki akcji po prawej stronie.
- Zmniejsz okno startowe do logo aplikacji i jej wersji; wskaźnik postępu następuje po ustawieniu zredukowanego ruchu.
- Zapamiętaj rozmiar i położenie okna aplikacji i odzyskaj je bezpiecznie, jeśli zapisany monitor nie jest już podłączony.
- Utrzymuj kontrolę OBS / Streamalters na emeryturze. Istniejące profile pozostają czytelne, a działania na emeryturze nie mogą być wykonywane.

Nie jest wymagana aktualizacja oprogramowania firmowego ani flash. DeckPilot Atelier pozostaje w 1.0.12 i firmware pozostaje w 1.1.1.
