DeckPilot 2.1.6 и DeckPilot ателье 1.0.12 сделать прошивку Atelier явной и извлекаемой.

- Переместите деструктивную прошивку в рухнувшие передовые операции и требуйте ввода `EFFACER` перед написанием.
- Объясните, что плата перестает перечисляться в качестве клавиатуры после стирания, покажите точные шаги восстановления с двойным сбросом RST / GND и сохраните действие восстановления Atelier доступным после стирания или прерванной вспышки.
- Firmware остается 1.1.1; нет DeckPilot Требуется смена аппаратного обеспечения.

Валидация включает проверку прошивки и приложений, а также автоматизацию пользовательского интерфейса Windows для расширенного контроля стирания, безопасность без устройства и руководство по восстановлению RST / GND. Сам сброс по-прежнему требует физической платы.
